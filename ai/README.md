## Structure of Folder AI

```
graduation-project-smart-surveillance/ai/
│
├── configs/               <- Configuration files (YAML) for models
├── data/                  <- Dataset loading and preprocessing modules
├── models/                <- Model architectures and network definitions
├── train/                 <- Training pipeline and optimization logic
├── evaluation/            <- Evaluation metrics and validation scripts
├── inference/             <- Inference and prediction scripts
├── utils/                 <- Utility functions and helper modules
│
├── experiments/           <- Experiment logs and configurations
├── checkpoints/           <- Saved model weights
├── results/               <- Output results and visualizations
│
├── tests/                 <- Unit tests
├── scripts/               <- Helper scripts (train, eval, etc.)
|
├── imgs/                  <- Images for documentation
|
└── main.py                <- Main entry point
```
