## Description
An AI-powered smart surveillance system that uses computer vision and IoT sensors to automatically detect abnormal, suspicious, and safety-critical events in real time then send instant alerts to enable fast, intelligent responses to potential threats while reducing reliance on continuous human monitoring.

---

## Overview
Traditional surveillance systems depend heavily on continuous human monitoring and passive video recording, limiting their ability to detect threats in real time.

This project introduces a **Smart Surveillance and Safety System** that leverages **Artificial Intelligence (AI)**, **Computer Vision**, and **Internet of Things (IoT)** technologies to automate detection, analyze behavior in real-time, and provide intelligent responses.

---

## Objectives
- Automate abnormal activity detection  
- Reduce reliance on manual monitoring  
- Improve response time to incidents  
- Minimize false alarms using sensor + AI fusion  
- Enhance public safety and operational efficiency

## Methodology

1. Capture live video streams  
2. Process using edge AI models  
3. Calculate abnormal behavior probability  
4. Trigger alerts when threshold is exceeded  
5. Use sensors to activate specialized models  
6. Send data to backend for validation  
7. Notify users via dashboard
