API Documentation

POST /api/face/add-face/{cameraId}

Uploads and associates a face image with a specific camera. The face will be stored and linked to the camera for identification purposes.

Parameters:

cameraId (path): int - The ID of the camera to associate the face with
file (form-data): IFormFile - The image file containing the face

Request Headers:

Content-Type: multipart/form-data
Authorization: Bearer {token} (if authentication is required)

Success Response (200):

{
  "isSuccess": true,
  "message": "Face added successfully",
  "data": {
    "id": 1,
    "url": "path/to/face/image.jpg",
    "cameraId": 1,
    "createdAt": "2026-05-01T12:34:56Z"
  }
}

Error Response (400/500):

{
  "isSuccess": false,
  "message": "Error message describing what went wrong",
  "data": null
}

Supported Image Formats:

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • GIF (.gif)
  • BMP (.bmp)

Testing Steps:

  1. Configure the API base URL (e.g., https://localhost:7274)
  2. If your API requires authentication, paste your JWT token
  3. Enter a valid Camera ID
  4. Select an image file from your system
  5. Click "Upload Face" button
  6. View the response in the Response panel
